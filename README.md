# سامانه هوشمند مدیریت عملیات و کیوسی نصب پرده و شید (طلائیه)

یک وب‌اپلیکیشن پیش‌رونده (PWA) تخصصی و بدون نیاز به سرور (Zero-Cost / Serverless) طراحی‌شده ویژه مجموعه‌های دکوراسیون، پرده و شید جهت **مدیریت زمان‌بندی ماهانه، دیسپچ اکیپ‌های نصب، انتقال اطلاعات فروش و نظارت دو لایه کنترل کیفیت (QC)**.

---

## 🌟 قابلیت‌های برجسته سیستم

### ۱. پنل مدیر کیوسی (QC Manager)
* **تقویم ماهانه و کانبان ۴ روزه:** قابلیت زمان‌بندی پروژه‌ها تا ۳۰ روز آینده و مشاهده در نمای روزانه یا ۴ ستونه.
* **کنترل پنجره دید تکنسین‌ها (Visibility Window):** اسلایدر هوشمند برای مشخص کردن اینکه تکنسین‌ها تا چند روز آینده را ببینند (مثلاً ۱ تا ۱۴ روز). برنامه‌های فراتر از این بازه برای تکنسین‌ها پنهان می‌ماند.
* **فرم جامع مأموریت:**
  * ثبت آدرس و لینک مسیریابی خودکار (نشان / بلد / گوگل مپ).
  * ثبت مشخصات فنی: تعداد لت شید، تعداد لت پرده، نوع موتور (سامفی، زنجیری و...).
  * **پیوست تصویر پروپوزال فروش:** امکان آپلود عکس‌های برگه سفارش واحد فروش جهت بررسی مستقیم تکنسین در محل.
  * **بانک ابزار هوشمند با دکمه «فول ابزار»:** انتخاب یک‌کلیکه تمامی تجهیزات استاندارد با قابلیت انتخاب موردی و یادداشت ابزار ویژه.
* **میز کار کیوسی (QC Desk):** بررسی عکس‌های ارسالی بعد از نصب، ثبت نمره کیفی (۱ تا ۵ ستاره) و درج اظهارنظر رسمی کیوسی.
* **کارتابل تیکت‌های فوری و کسری‌ها:** دریافت آنی گزارش کسری پارچه، خرابی موتور یا ایراد دیوار از سر پروژه.
* **مدیریت اعضای اکیپ:** تعریف سرپرستان و تکنسین‌ها با شماره موبایل و رمز عبور.
* **پشتیبان‌گیری کامل (JSON Backup):** خروجی و بازیابی با یک کلیک.

---

### ۲. پنل موبایل تکنسین‌ها و سرپرستان (PWA Mobile)
* **ورود سریع با شماره و رمز:** ورود با شماره موبایل و رمز تعیین‌شده توسط مدیر.
* **دید محدود به پنجره مجاز:** دسترسی فقط به روزهای تاییدشده توسط مدیر کیوسی.
* **کارت مأموریت هوشمند:**
  * دکمه تماس مستقیم با کارفرما.
  * دکمه مسیریابی با اپ‌های ایرانی (نشان / بلد) و گوگل‌مپ.
  * مشخصات دقیق تعداد لت‌ها و نوع مکانیزم.
  * دکمه **مشاهده پروپوزال فروش** با قابلیت زوم کامل.
  * دکمه **چک‌لیست بارگیری ابزار از انبار** برای تیک‌زدن وسایل داخل خودرو.
* **گردش کار اجرای نصب:**
  * «حرکت به سمت پروژه» ⬅️ «رسیدم سر پروژه / شروع نصب» ⬅️ «ثبت اتمام نصب و ارسال عکس».
* **دکمه اضطراری ثبت تیکت کسری یا خرابی سر پروژه.**

## 🚀 نحوه اجرای پروژه روی سیستم شخصی

### ۱. اجرای نسخه توسعه (Dev Server):
```bash
npm install
npm run dev
```
سپس آدرس نمایش داده شده (مثلاً `http://localhost:5173`) را در مرورگر باز کنید.

### ۲. ساخت فایل‌های نهایی (Build):
```bash
npm run build
```
پوشه `dist` حاوی تمام فایل‌های نهایی و آماده انتشار است.

## 🌐 نحوه بالا آوردن روی GitHub Pages (۱۰۰٪ رایگان)

یک فایل تنظیمات انتشار خودکار در مسیر `.github/workflows/deploy.yml` قرار داده شده است. کافیست:

1. کدهای این پوشه را به یک مخزن (Repository) در گیت‌هاب Push کنید:
   ```bash
   git init
   git add .
   git commit -m "feat: سامانه عملیات و کیوسی نصب پرده و شید"
   git branch -M main
   git remote add origin https://github.com/نام_کاربری_شما/نام_مخزن.git
   git push -u origin main
   ```
2. در گیت‌هاب، به تب **Settings** مخزن بروید و در بخش **Pages**، منبع را روی **GitHub Actions** بگذارید.
3. گیت‌هاب به صورت خودکار پروژه را می‌سازد و لینک سایت رایگان شما را تحویل می‌دهد!
